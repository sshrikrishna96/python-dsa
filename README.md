# 🧠 Problem-Solving Approach

For every problem I follow:

1. Understand the problem.
2. Identify the pattern.
3. Develop a brute-force approach.
4. Analyze the complexity.
5. Optimize the solution.
6. Write clean Python code.
7. Test edge cases.

---

# 📝 Solution Format

Each problem should contain:

- Problem statement
- Pattern
- Approach
- Time complexity
- Space complexity
- Clean implementation
- Test cases
